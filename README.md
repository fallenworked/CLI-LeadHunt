# LEAD HUNTER — LOCAL EDITION

[English](README.en.md) · **Русский**

Локальный терминальный охотник за лидами для Windows 10/11. Ищет реальные
POI-объекты OpenStreetMap через публичный Overpass API, сохраняет их в SQLite,
помогает вести статусы и заметки, экспортирует CSV и автономный HTML-отчёт.



```powershell
python main.py
```

```
LEAD HUNTER · LOCAL EDITION
«Каждый найденный лид — новая возможность»
```

## Возможности

- Тёмный терминальный интерфейс: графит, кровь, ASCII-жнец, живой прогресс.
- Реальный поиск по OpenStreetMap: города, ниши, ключевые слова, радиус,
  лимит, фильтры «только с телефоном», «только с адресом», «включать сайты».
- Несколько зеркал Overpass опрашиваются параллельно. Ошибка одного зеркала
  показывается и не роняет поиск.
- SQLite-база: лиды, история поисков, связь лидов с поисками, настройки,
  кеш координат городов.
- Дедупликация внутри поиска и между поисками по названию, координатам,
  телефону или адресу. Статусы и заметки пользователя не перезаписываются.
- Воронка статусов: новый, на связи, интерес, предложение, клиент, отказ.
- Просмотр лидов с фильтрами, страницами, карточкой, картами и удалением.
- История: детали запуска, ошибки, повтор с теми же параметрами, экспорт.
- Экспорт CSV (UTF-8 BOM, `;` для Excel) и standalone HTML-отчёт с тёмной
  темой, поиском, фильтрами, сортировкой и статистикой. HTML работает офлайн.
- Управление источниками: реальная проверка зеркал, добавление, удаление,
  сброс, включение/отключение OSM.
- Статистика по базе, статусам, городам, нишам и активности за 7 дней.
- CLI-режимы для автоматизации и проверки без интерактивного меню.

## Установка

Нужен Python 3.10+ (проверено на 3.12) и интернет для поиска.

```powershell
git clone https://fallenworked/CLI-LeadHunt.git
cd CLI-LeadHunt
python -m pip install -r requirements.txt
python main.py
```

Зависимости: `rich` (терминальный UI), `questionary` (меню и ввод),
`requests` (Overpass, Photon, Nominatim). Больше ничего не требуется.

## Запуск

### Интерактивный режим

```powershell
python main.py
```

Главное меню:

1. Начать поиск лидов.
2. Сохранённые лиды.
3. Поиск по сохранённым.
4. История поисков.
5. Экспорт CSV / HTML.
6. Управление источниками.
7. Настройки.
8. Статистика.
9. Выход.

`Ctrl+C` в вопросах возвращает назад, в главном меню — выходит.
Стрелки и `Enter` работают во всех меню.

### Поиск без меню

```powershell
python main.py --search "Москва" --niche "стоматология" --radius 3000 --limit 120
python main.py --search "Казань" --niche "кафе" --format both
python main.py --city "Сочи" --niche "отель" --only-phone
```

Полезные флаги:

| Флаг | Назначение |
| --- | --- |
| `--search ГОРОД` | выполнить поиск и выйти |
| `--city ГОРОД` | альтернативный способ передать город |
| `--niche НИША` | ниша из справочника или произвольное ключевое слово |
| `--keywords "a,b"` | дополнительные ключевые слова |
| `--radius 5000` | радиус в метрах (500–20000) |
| `--limit 250` | максимум лидов (10–1000) |
| `--only-phone` | только лиды с телефоном |
| `--require-address` | только лиды с адресом |
| `--include-website` | не отбрасывать бизнесы с сайтом |
| `--format csv\|html\|both` | экспорт после поиска |
| `--check` | проверить доступность зеркал Overpass |
| `--no-anim` | без анимации запуска |
| `--version` | версия |

### Проверка источника

```powershell
python main.py --check
```

Команда отправляет реальные запросы к зеркалам и показывает HTTP-ошибки,
таймауты и задержки. Никаких «онлайн» без ответа сети.

## Как работает поиск

1. Город ищется в локальном справочнике (60+ городов). Неизвестный город
   геокодируется через Photon, затем через Nominatim; координаты кешируются.
2. Строится Overpass-запрос по тегам выбранной ниши либо по названию для
   произвольного ключевого слова. Используется bbox выбранного радиуса.
3. Зеркала Overpass опрашиваются параллельно; берётся первое с непустым
   ответом, остальные ошибки попадают в отчёт.
4. Из OSM-тегов извлекаются название, телефон, email, адрес, часы, сайт,
   соцконтакты, тип бизнеса и координаты. Объекты без названия отбрасываются.
5. Фильтры применяются до сохранения; по умолчанию бизнесы с сайтом не нужны.
6. Дедупликация: название + координаты (~100 м), иначе название + телефон,
   адрес или город.
7. Результат сохраняется в SQLite, связывается с записью истории поиска.
   Повторный поиск обновляет недостающие поля, но не статус и не заметки.

## Ниши

Встроено 25 ниш: стоматология, кафе, ресторан, парикмахерская, салон красоты,
автосервис, аптека, фитнес, юрист, автомойка, магазин одежды, пекарня, цветы,
мебель, зоомагазин, оптика, гостиница, ветклиника, бар, книжный, ювелирный,
пиццерия/фастфуд, кинотеатр, бассейн/спортцентр, тату-салон.

Для остальных случаев выбери «Другая ниша / ключевой запрос»: поиск пойдёт по
совпадению названия в OSM.

## Источник и ограничения

Единственный рабочий источник — **OpenStreetMap / Overpass**. Старая версия
проекта тоже использовала только его. Google Places, Яндекс.Карты и 2ГИС
требуют ключей, договоров или коммерческих условий, поэтому они не
имитируются.

Учитываются правила источника:

- собственный `User-Agent` приложения;
- настраиваемый минимальный интервал между поисками;
- таймауты и лимиты Overpass;
- данные OSM распространяются по лицензии ODbL, при публикации указывай
  «© OpenStreetMap contributors».

Публичные зеркала иногда отвечают `502`, `429` или таймаутом. Это нормально:
приложение покажет ошибку, попробует другие зеркала и не подменит результат
выдуманными лидами.

## Что удалено из старой версии

- Cloudflare Worker, D1, миграции и `wrangler`;
- веб-интерфейс, статические ассеты и серверные API;
- Google/Telegram OAuth, демо-вход и аккаунты;
- подписки, оплата, юридические страницы;
- cron/автопоиск и Telegram-бот;
- AI-чат на внешних API (Gemini/DeepSeek).

Эти функции зависели от облака, секретов и платёжных провайдеров. В локальной
версии их нет, но сохранена и усилена главная ценность: реальный поиск лидов,
база, история, статусы и экспорт.

```powershell

```

Покрыто: разбор OSM, фильтры, дедупликация, геокодер по словарю,
SQLite-хранилище, дедупликация между поисками, изоляция ошибок источника,
CSV/HTML-экспорт и экранирование HTML. Тесты не обращаются к сети.

Живая проверка источника:

```powershell

```

## Диагностика

- Все ошибки экранов и поиска пишутся в `data/lead_hunter.log`.
- Если поиск не находит город, проверь название или укажи ближайший крупный
  город.
- Если все зеркала недоступны: проверь интернет/файрвол, нажми
  «Управление источниками» → «Проверить зеркала», при необходимости добавь
  другое зеркало Overpass.
- Если в терминале нет цветов/рамок, запусти Windows Terminal или включи
  поддержку VT в консоли; приложение само пытается включить UTF-8 и ANSI.
